STAR WARS API
======================================================================

DESCRIPTION
-----------
Ce projet consiste à interagir avec l’API Star Wars (SWAPI), une API REST
publique permettant d’accéder aux données de l’univers Star Wars :
personnages, films, planètes, vaisseaux, espèces, etc.

L’objectif est d’écrire des scripts capables de :
    - consommer une API REST,
    - récupérer des données structurées en JSON,
    - gérer des requêtes HTTP,
    - traiter et afficher les résultats selon les exigences du projet.

Ce projet fait partie de l’apprentissage des interactions entre Python,
les APIs et les formats de données web.

----------------------------------------------------------------------
LEARNING OBJECTIVES
-------------------
À la fin de ce projet, vous devez être capable d’expliquer clairement :

How to consume a REST API
    Comprendre comment envoyer une requête HTTP et récupérer une réponse JSON.

How to parse JSON data
    Extraire et manipuler les informations retournées par l’API.

How to handle HTTP requests in Python
    Utiliser un module comme requests ou urllib pour interagir avec une API.

How to work with paginated APIs
    Gérer les réponses réparties sur plusieurs pages (si applicable).

How to process and format API results
    Organiser les données reçues pour les afficher dans le format demandé.

REQUIREMENTS
------------
GENERAL
    - Un fichier README.md est obligatoire à la racine du projet.
    - Éditeurs autorisés : vi, vim, emacs.
    - Tous les fichiers seront interprétés/compilés sur Ubuntu 14.04 LTS
      avec Python 3.x (selon le projet).
    - Tous les fichiers doivent se terminer par une nouvelle ligne.
    - Tous les fichiers doivent être exécutables.
    - La première ligne de tous les fichiers doit être exactement :
          #!/usr/bin/python3
    - Le code doit respecter PEP 8 (version 1.7.*).
    - Vous ne pouvez importer que les modules autorisés par le projet.
    - Le programme doit gérer correctement les erreurs HTTP et les cas limites.

OBJECTIF GLOBAL
---------------
Ce projet vous apprend à :
    - interagir avec une API REST réelle,
    - comprendre les mécanismes de requêtes HTTP,
