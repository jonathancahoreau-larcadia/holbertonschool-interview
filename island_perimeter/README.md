======================================================================
ISLAND PERIMETER
======================================================================

DESCRIPTION
-----------
Ce projet consiste à calculer le périmètre d’une île représentée sous forme
de grille 2D. L’île est composée de cases valant 1 (terre) et entourée par
des cases valant 0 (eau). L’objectif est d’écrire une fonction Python qui
retourne le périmètre total de l’île.

Règles :
    - Une case de terre contribue à 4 côtés.
    - Chaque côté partagé avec une autre case de terre retire 2 côtés.
    - La grille contient une seule île (pas de plusieurs masses de terre).
    - La grille est entièrement entourée d’eau.

Ce projet est un exercice classique de logique et de manipulation de matrices.

----------------------------------------------------------------------
OBJECTIF GLOBAL
---------------
Ce projet vous apprend à :
    - parcourir une grille 2D,
    - analyser les voisins d’une case,
    - calculer un périmètre en fonction des connexions,
    - écrire du code propre sans dépendances externes,
    - documenter correctement vos fonctions et modules,
    - respecter des contraintes strictes d’exécution et de style.
