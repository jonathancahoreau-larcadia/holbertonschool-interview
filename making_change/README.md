DESCRIPTION
-----------
Ce projet consiste à résoudre un problème classique d’algorithmique :
déterminer le **nombre minimal de pièces** nécessaires pour atteindre un
montant donné.

L’objectif est d’écrire un programme Python capable de calculer la solution
de manière efficace, en respectant les contraintes imposées par le projet.

Ce type de problème est souvent lié à :
    - la programmation dynamique,
    - les algorithmes gloutons (selon les pièces disponibles),
    - l’optimisation combinatoire.

OBJECTIF GLOBAL
---------------
Ce projet vous apprend à :
    - analyser un problème d’optimisation,
    - choisir la bonne stratégie algorithmique,
